商品图工坊

打开网页即可使用。抠图与模板海报在当前浏览器里完成，无按张收费，不需要安装软件。

  1. 拖入图片，或粘贴截图，自动去除背景。第一次使用会下载并缓存模型。
  2. 检查边缘。手套等相连物体可用“修补边缘”擦除，或圈住商品保留。
  3. 设置白底和尺寸，下载单图或批量 ZIP。
  4. 切换“封面海报”填写标题；“详情套图”导出封面、商品展示和细节，填写卖点会增加商品信息页。

图片保存在此浏览器的本地存储，刷新可继续。换设备、无痕模式或清理网站数据会失去素材，请及时下载。下载文件在浏览器下载目录；移出素材不影响你的原图和已下载文件。

原图长边导出上限为 6000 px。原始色彩与拍摄角度保留，抠图不会自动修正透视或重绘包装。AI 创作需自备接口，可能按服务商标准计费，且生成式模型可能改动细节。

抠图使用 U²-Net / ISNet 与 ONNX Runtime Web，预处理参考 rembg。第三方授权见项目 THIRD_PARTY.md。

本应用独立实现界面与海报模板，参考 PicsetAI 公开功能流程，与该网站无关联。
